>Посмотреть статус репозитория на **локальной машине** (что изменилось в **локали** относительно <ins>облака гитхаб</ins>?)
```bash
git status # без предварительных команд просто то что в локали сохранилось последним
```

>Посмотреть статус репозитория на **облачном ресурсе** (что изменилось в **гитхаб** относительно <ins>локального репозитория</ins>)
```bash
git fetch origin # запрос у ГИТХАБ новых последних коммитов: локаль гит -> гитхаб
git status # статус на ГИТХАБ
```
