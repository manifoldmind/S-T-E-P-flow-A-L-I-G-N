# MARKER TAGS for MINDWORK

Теги для аналитических записок, черновиков, онтологии проекта (`.md` файлы).

Они обычно подразумевают развёрнутое описание идей, решений, контекста.

---

## Основные теги MINDWORK

| Маркер       | Назначение                                                                                   |
|--------------|----------------------------------------------------------------------------------------------|
| `# GROK:`    | Глубокое осмысление сложной концепции или связей. Часто — корневой тег онтологии.            |
| `# DEEP:`    | Детальное изучение отдельного аспекта (спецификация, RFC, ссылка на внешний источник).       |
| `# NOTE:`    | Техническое или логическое пояснение (может быть как в код, так и в доки).                   |
| `# ANALYZED:`| Результат анализа задачи/бага на концептуальном уровне.                                      |
| `# IDEA:`    | Сырая идея, не оформившаяся в задачу.                                                        |
| `# QUE:`     | Открытый вопрос для дальнейшего исследования.                                                |
| `# ANS:`     | Ответ на вопрос, фиксация вывода.                                                            |
| `# BACKLOG:` | Принятая в план доработка (как задача).                                                      |
| `# WARN:`    | Предостережение о потенциальной проблеме (актуально в дизайн-документах).                    |
| `# HACK:`    | Временное концептуальное решение, требующее замены.                                          |

> **Примечание:** В документах можно использовать и другие теги из основного справочника, если это уместно.
> Основное отличие — `# GROK:` и `# DEEP:` рождаются именно здесь, а в коде появляются лишь как короткие ссылки.
