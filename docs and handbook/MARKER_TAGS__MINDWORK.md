# MARKER TAGS for MINDWORK

Теги для аналитических записок, черновиков, онтологии проекта (`.md`-файлы).  
Подразумевают развёрнутое описание идей, решений, контекста.

Формат: `# TAG: описание` в начале строки.

---

## 🧠 Основные теги

| Маркер         | Назначение                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `# GROK:`      | Глубокое погружение в сложную концепцию, взаимосвязь идей. Может стать корнем онтологии.                                             |
| `# DEEP:`      | Детальное изучение конкретного аспекта (спецификация, RFC, ссылка на источник).                                                      |
| `# NOTE:`      | Техническое или логическое пояснение (реализация, архитектура).                                                                      |
| `# ANALYZED:`  | Результат анализа задачи/бага на концептуальном уровне (контекст).                                                                   |
| `# IDEA:`      | Сырая идея, не оформившаяся в задачу.                                                                                                |
| `# QUE:`       | Открытый вопрос для дальнейшего исследования.                                                                                        |
| `# ANS:`       | Ответ на вопрос, фиксация вывода.                                                                                                    |
| `# BACKLOG:`   | Принятая в план доработка (как задача).                                                                                              |
| `# WARN:`      | Предостережение о потенциальной проблеме (актуально в дизайн-документах).                                                            |
| `# HACK:`      | Временное концептуальное решение, требующее замены.                                                                                  |
| `# PLAN:`      | План действий (что и зачем менять).                                                                                                  |
| `# CHILLOUT:`  | Замедляемся в работе: возвращаемся к каким-либо шагам/этапам и уточняем недостающие детали. Особенно подходит для пометки в диалоге. |

---

## 🧩 Теги методологии A.L.I.G.N.

Эти маркеры отражают фазы выравнивания понимания перед действием.  
Подробное описание подхода — в [methodology A.L.I.G.N..md](https://github.com/manifoldmind/S-T-E-P-flow-A-L-I-G-N/blob/main/templates/methodology%20A.L.I.G.N..md).

| Маркер            | Назначение                                                                                                       |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- |
| `# SYSTEMATIZE:`  | Систематизация по A.L.I.G.N.: фиксация целей, ограничений, инструментов, плана шагов, подтверждение.             |
| `# CUTTING:`      | Огранка — перевод сухого ТЗ или термина на житейскую аналогию, понятную новичку.                                 |
| `# ALIGN:`        | Общий маркер начала цикла ALIGN (опционально, когда нужно явно выделить блок выравнивания целиком).              |

---

> **Примечание:** Теги `# GROK:` и `# DEEP:` рождаются именно здесь, а в коде могут появляться как ссылки на соответствующие аналитические записки. Все теги можно комбинировать в рамках одного диалога или документа.
