# MARKER TAGS for CODE

Краткий справочник тегов, используемых в комментариях к исходному коду (`//`, `#`, `/* */`).

Все теги: `# TAG: описание` в начале строки.

---

## Повествовательные (обязателен комментарий)

| Маркер       | Слой     | Назначение                                                                 |
|--------------|----------|----------------------------------------------------------------------------|
| `# NOTE:`    | tech     | Техническое пояснение: архитектура, реализация.                            |
| `# WARN:`    | tech     | Предупреждение о скрытой проблеме (гонка, зависимость).                    |
| `# HACK:`    | tech     | Временное неочевидное решение.                                             |
| `# ANALYZED:`| context  | Анализ задачи/бага на языке логики, не кода.                               |
| `# IDEA:`    | context  | Продуктовая идея, ещё не задача.                                           |
| `# QUE:`     | any      | Вопрос (технический или по логике).                                        |
| `# ANS:`     | any      | Ответ на `# QUE:`.                                                         |
| `# BACKLOG:` | any      | Принятая в бэклог задача.                                                  |

---

## Результативные (факт, статус)

| Маркер     | Значение                                                            |
|------------|---------------------------------------------------------------------|
| `# DONE:`  | Финально готово, продакшн (ставить в конце)                         |
| `# MAKED:` | Реализовано, но не факт, что протестировано                         |
| `# FIXED:` | Исправление после `# FIXME:` выполнено                              |
| `# STUB:`  | Заглушка, не используется                                           |
| `# INIT:`  | Заготовка структуры                                                 |
| `# PROC:`  | В процессе (WIP), удалить перед мерджем                            |
| `# TMP:`   | Временный код, будет удалён                                         |
| `# HOLD:`  | Приостановлен, может вернуться                                      |
| `# ARCHV:` | Архив, для истории                                                  |

---

## Побудительные (что сделать)

| Маркер      | Значение                                                     |
|-------------|--------------------------------------------------------------|
| `# TODO:`   | Запланированная задача                                       |
| `# FIXME:`  | Известный баг/неоптимальность, требуется исправление         |
| `# REFACT:` | Необходим рефакторинг                                        |
| `# PLAN:`   | План действий (что и зачем менять)                           |
| `# MAKEME:` | Указание реализовать                                         |
| `# DEBUG:`  | Отладочный код, не для продакшна                             |
| `# KEEP:`   | Не удалять этот блок                                         |
| `# ADD:`    | Маркер добавления нового блока                               |
