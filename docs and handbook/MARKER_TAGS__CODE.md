# MARKER TAGS for CODE

Краткий справочник тегов для комментариев в исходном коде (`//`, `#`, `/* */`).  
Формат: `# TAG: описание` в начале строки.  
Полный сводный справочник и теги методологии A.L.I.G.N. см. в [MARKER_TAGS__SIGNATURES.md](https://github.com/manifoldmind/S-T-E-P-flow-A-L-I-G-N/blob/main/docs%20and%20handbook/MARKER_TAGS__ALL_SIGNATURES.md).

---

## 📝 Повествовательные (обязателен комментарий)

| Маркер        | Значение                                                                 |
|---------------|--------------------------------------------------------------------------|
| `# NOTE:`     | Техническое пояснение архитектуры, реализации, выбора решения.           |
| `# WARN:`     | Предупреждение о неочевидной проблеме, ловушке.                          |
| `# HACK:`     | Временное или нестандартное решение, требующее замены.                   |
| `# ANALYZED:` | Анализ задачи/бага на языке логики, не кода (контекст).                  |
| `# IDEA:`     | Сырая продуктовая идея, ещё не задача.                                  |
| `# QUE:`      | Вопрос к блоку (технический или по логике).                              |
| `# ANS:`      | Ответ на вопрос `QUE:`.                                                |
| `# BACKLOG:`  | Принятая в бэклог задача (техническая или продуктовая). По сути `CONFIRM` для плана реализации, можно ставить в конце принятого блока.                  |

## ✅ Результативные (статус, факт)

| Маркер     | Значение                                                                          |
|------------|-----------------------------------------------------------------------------------|
| `# DONE:`  | Финально готово, протестировано, в продакшне. Ставится в конце блока.             |
| `# MAKED:` | Реализовано, но не факт, что протестировано (промежуточная галочка).              |
| `# FIXED:` | Исправление после `FIXME:` выполнено. Ставится внутри блока.                      |
| `# STUB:`  | Заглушка / фундамент, не используется.                                            |
| `# INIT:`  | Заготовка структуры, будет дорабатываться.                                        |
| `# PROC:`  | Блок в процессе разработки (WIP). Удалить перед мерджем.                          |
| `# TMP:`   | Временный код, будет удалён.                                                      |
| `# HOLD:`  | Приостановлено, может вернуться в работу.                                         |
| `# ARCHV:` | Архив, оставлен для истории, не для возвращения.                                  |
| `# RETURNED:`   | Решение возвращено в работу.                                                 |

## ⚡ Побудительные (действия)

| Маркер      | Значение                                                      |
|-------------|---------------------------------------------------------------|
| `# TODO:`   | Запланированная задача.                                       |
| `# FIXME:`  | Баг или неоптимальность, требуется исправление.               |
| `# REFACT:` | Требуется рефакторинг.                                        |
| `# PLAN:`   | Зафиксированный план действий.                                |
| `# MAKEME:` | Прямое указание реализовать.                                  |
| `# DEBUG:`  | Отладочный код, не для продакшна.                             |
| `# KEEP:`   | Категорически не удалять этот блок.                           |
| `# ADD:`    | Маркер добавления нового блока кода.                          |
| `# REDEF:`  | Переопределение блока.                                        |
| `# REPLACE:`| Требуется замена на альтернативный блок.                      |
